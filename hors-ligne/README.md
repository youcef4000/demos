# Démos mises hors ligne

Les dossiers ici ne sont publiés nulle part. Les démos en ligne sont dans le dépôt public
`youcef4000/bornz-demos` (GitHub Pages). Pour remettre une démo en ligne : copier `hors-ligne/<slug>` dans
`sites/<slug>` de `bornz-demos`, ajouter son entrée dans `sites/demos.json`, puis pousser sur `main`.
Avant, vérifier qu'elle ne contient rien de privé : ce dépôt-là est public.

- `melissa-atelier` : site et espace atelier bloqués à la demande, en attente de validation.
